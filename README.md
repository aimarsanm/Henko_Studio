# Henko_Studio

Desde la carpeta raíz del repositorio, entra en la carpeta de la aplicación e inicia Vite:

```powershell
cd .\henko-studio
npm install
npm run dev
```

Abre en el navegador la dirección que muestre Vite, normalmente `http://localhost:5173/`.

Para generar y previsualizar la versión de producción:

```powershell
npm run build
npm run preview
```
